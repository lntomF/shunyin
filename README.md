# SHUNYIN

SHUNYIN 是一个面向摄影作品发布的本地水印工作台。它基于浏览器运行，重点放在图片导入、拍摄信息整理、水印样式预览和成片导出，让摄影师可以更快把照片整理成适合发布的作品图。

当前版本以本地工作流为主，不需要登录即可完成导入、编辑、预览和导出。

## 主要功能

- 本地图片导入：支持导入 JPEG、PNG、WEBP 图片，并可一次处理多张照片。
- EXIF 信息编辑：可查看和手动修改相机、镜头、光圈、快门、ISO 等展示信息。
- 水印样式预览：提供多种水印模板，可在导出前实时查看照片效果。
- 主题切换：支持白天主题和暗色主题，适配不同使用环境。
- 本地导出：支持导出 JPG 或 PNG 成片，并可选择不同输出质量。
- 批量处理：可在同一个工作区中管理多张图片，并批量导出。
- 本地会话恢复：最近编辑过的本地工作区会保存在当前浏览器中，方便继续处理。
- OpenAI 图片生成：输入提示词生成一张图片，并直接进入现有水印编辑与导出流程。

## OpenAI 图片生成配置

图片生成通过 Vite 本地服务端代理调用固定的 SHUNYIN 中转站：`https://api.shunyin.eu.cc/v1`。你可以直接在网页上填写 API Key，抓取可用模型列表，并选择图片模型。

1. 运行 `npm run dev`，打开首页。
2. 选择「AI 生图」进入 AI 图片工作台。
3. 在网页中填写 API Key；浏览器会把它保存在本地，下次打开无需再次填写。
4. 点击「抓取模型」，在选择框中选择一个 image 模型；如果中转站不支持 `/models`，也可以手动输入模型 ID。
5. 输入提示词生成图片，或上传图片后输入编辑提示词进行图片编辑。

生成和编辑结果会留在 AI 图片工作台，不会自动跳转到水印编辑器。如果你希望保留默认配置，也可以在 `.env.local` 设置 `OPENAI_API_KEY`、`OPENAI_IMAGE_MODEL` 作为 fallback。
